# Miftahul Alam Adib — Portfolio

Built with React + Vite.

## Setup

```bash
npm install
npm run dev
```

## Image files needed in /public

Place these two files in the `public/` folder before pushing:
- `cover.jpg` — the neon strands background image (puscas-adryan-unsplash)
- `profile.jpg` — your circular profile photo

## Build for production

```bash
npm run build
```
